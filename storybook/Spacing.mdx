## Spacing Scale

Use the spacing scale for padding, gaps and offsets inside components.

<SpacingScale
  config={{
    gridSize: spacing.grid.value,
    direction: 'horizontal',
  }}
  scales={spacing.scale.map((token) => ({
    name: token.name,
    token: token.variable,
    value: token.value,
  }))}
/>

## Vertical Rhythm

Component heights are multiples of <code>{spacing.grid.variable}</code> so they
line up with the background grid.

<SpacingScale
  config={{
    gridSize: spacing.grid.value,
    direction: 'vertical',
  }}
  scales={rhythmMultiples.map((multiple) => ({
    name: `${multiple}×`,
    token: `calc(var(${spacing.grid.variable}) * ${multiple})`,
    value: multiple * spacing.grid.value,
  }))}
/>
